# Change Log

All notable changes to the "nagular" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [1.0.2]

- The four navigation actions (Go to TS / Go to Html / Go to Style / Go to Test) are now grouped together at the top of the editor title bar, using negative menu orders so that other extensions' icons can no longer be interleaved between them.

## [1.0.1]

- Coloured and readable navigation badges (SVG light/dark) for the Go to TS, Go to Html, Go to Style and Go to Test actions
- Dedicated action icons for each navigation command
- Hardened extension packaging (`.vscodeignore`)
- Multi-OS CI (macOS, Ubuntu, Windows) with publication gated on the tag

## [1.0.0]

- Initial release
